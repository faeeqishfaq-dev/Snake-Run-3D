Unity Built-in Render Pipeline finish line material.

Import:
1. Extract this folder into your Unity project's Assets folder.
2. Use FinishLine_Mat.mat on a Plane/Quad/Mesh Renderer.
3. For a narrow finish strip, scale the mesh or adjust material tiling in the Inspector.

Included:
- FinishLine_Mat.mat
- FinishLine_Albedo.png
- FinishLine_Normal.png
- FinishLine_MetallicSmoothness.png

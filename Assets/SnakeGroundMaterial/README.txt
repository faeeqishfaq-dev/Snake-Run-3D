SnakeGround Material - Built-in Render Pipeline

Included:
- SnakeGround_Chevron.png
- SnakeGround_Mat.mat (Standard shader)

Import options:
1) Drag the whole SnakeGroundMaterial_Assets folder into your Unity project's Assets folder.
2) Or import the included .unitypackage through Assets > Import Package > Custom Package.

Then assign SnakeGround_Mat to your track/ground MeshRenderer.

Recommended Standard shader settings:
- Metallic: 0
- Smoothness: 0.22
- Tiling: start at X=1, Y=2 or Y=3 depending on track length.
